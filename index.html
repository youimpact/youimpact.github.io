Claude 仕事メール

Claude 仕事メールは、所有者1人だけが自分の Mac で使う個人用のツールです。AI アシスタント（Claude）が、所有者自身の Gmail とカレンダーを扱えるようにします。一般向けのサービスではなく、ほかの人は利用できません。

できること

  • 所有者の Gmail を検索して、メールを読む
  • 返信の下書きを Gmail に保存する（送信はしません。送信は所有者が Gmail で確認してから自分で行います）
  • 所有者の Google カレンダーの予定を読み、追加・変更する

データの扱いは プライバシーポリシー をご覧ください。

Claude Work Mail

Claude Work Mail is a personal tool used only by its owner on the owner's own Mac. It lets an AI assistant (Claude) work with the owner's own Gmail and Google Calendar. It is not a public service and is not offered to anyone else.

  • Search and read the owner's Gmail messages
  • Save reply drafts in Gmail (it never sends mail; the owner reviews and sends drafts personally)
  • Read, create and update events in the owner's Google Calendar

See the Privacy Policy.
