プライバシーポリシー

最終更新日：2026年10月22日

Claude 仕事メール（以下「本ツール」）は、所有者1人だけが自分の Mac で使う個人用のツールです。所有者以外の利用者はいません。

扱うデータ

  • Gmail：メールの検索と閲覧、返信の下書きの保存（メールの送信は行いません）
  • Google カレンダー：予定の閲覧、追加、変更
  • Google アカウントの基本情報：どのアカウントでログインしたかを確かめるためのメールアドレス

データの使い方

  • 上のデータは、所有者自身の依頼に応えるためだけに使います。
  • ログインの情報（トークン）は所有者の Mac の中に保存し、外部のサーバーには保存しません。
  • データを第三者に販売、共有、提供することはありません。広告にも使いません。
  • 所有者が依頼した作業の範囲で、メールや予定の内容が AI アシスタント（Anthropic 社の Claude）に渡されます。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の利用と他アプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

アクセスの取り消し

所有者は Google アカウントの「サードパーティ製のアプリとサービス」 から、いつでも本ツールのアクセスを取り消せます。

Privacy Policy

Last updated: October 22, 2026

Claude Work Mail ("the tool") is a personal tool used only by its owner on the owner's own Mac. There are no other users.

Data accessed

  • Gmail: searching and reading messages, and saving reply drafts (the tool never sends mail)
  • Google Calendar: reading, creating and updating events
  • Basic account info: the email address, to confirm which account is signed in

How data is used

  • Data is used only to carry out the owner's own requests.
  • Sign-in tokens are stored on the owner's Mac only, not on any external server.
  • Data is never sold, shared with or transferred to third parties, and is never used for advertising.
  • Within tasks the owner requests, message and event content is processed by the AI assistant (Claude by Anthropic).

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke the tool's access at any time from Google Account > Third-party apps & services.
